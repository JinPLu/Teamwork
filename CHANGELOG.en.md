## 7.3.0 - 2026-08-13

**Teamwork is now lighter and follows your direction more faithfully: clear work runs directly, and defensive mechanisms written into a plan or handoff by an Agent are not treated as your approval.**

- **You say to continue → your settled boundaries still control the work → an Agent cannot turn its own SHA-256, receipt, or audit-test proposal into your requirement.**
- **The request is already clear → the work runs natively → no mandatory stage, project record, or readiness gate comes first.**
- **Parallel or independent help is genuinely useful → a subagent joins → missing optional roles do not block ordinary work.**
- **You run Update → Codex refreshes by default → Cursor and Claude Code are touched only when you select them explicitly.**
