# Cursor compatibility adapter

Cursor is an explicit compatibility and development target, not part of the
default Codex Update or validation path.

```bash
./install.sh cursor
./install.sh cursor-policy-copy
```

Paste the policy into Cursor User Rules if you choose this adapter. Teamwork
does not treat that manual state, a Cursor model mapping, or adapter freshness as
a blocker for Codex or ordinary project work.

The adapter exposes the same focused Skills and seven optional helper roles. It
creates no project document schema or migration state.
